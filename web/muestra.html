Botones

Formularios

Cada campo con su etiqueta; la ayuda y el error quedan unidos al control (aria-describedby).

Controles

Segmentado: una opción entre pocas (con las flechas del teclado). Pestañas: ← → también cambian.

Alertas

Estados: vacío, cargando y error

Todo gráfico o lista tiene los tres. "Reintentar" muestra la ruedita mientras trabaja. Con "reducir movimiento" el brillo del esqueleto no se mueve.

Diálogo
