# Navegadores: Chrome y Edge

- Chrome es el navegador principal: bucket `aw-watcher-web-chrome_Dremy`.
- Edge se deja como está: lo usa solo para PDFs; su extensión escribe en `aw-watcher-web-chrome` con hostname "unknown". Esos datos web no se usan, pero sus ventanas (títulos de PDF) sí cuentan en la clasificación.
